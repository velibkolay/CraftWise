# Icons: one symbol per concept (#308)

Reference for new code: before adding an icon, mark or inline symbol, find the concept here and use its
symbol. Textures are `Style.Media` (`CraftWise/UI/Style.lua`, generated by `tools/gen_addon_textures.py`),
colours are `Style.C` (Origami spec). Client art is referenced, never copied.

## Marks on items

| Concept | Symbol | Where |
|---|---|---|
| Junk (marked by you) | grey folded corner (`Media.fold`, `text3`, 13 units, top right) + icon desaturated and dimmed to `ns.JUNK_DIM` (55 %). **Never a coin.** | bag slots in Blizzard bags, Bagnon, Baganator (`BagIcons.lua`, `Baganator.lua`); Make/Bags page rows dim the icon the same way (`Pages/Bags.lua`) |
| Sell on the AH | gold folded corner (`Media.fold`, `coinGold`) | same slots |
| Keep | no mark on the slot; Bags page: icon desaturated (no dim) and a "Keep" tag | `Pages/Bags.lua` |
| Poor-quality item you did not mark | the client's own coin (`JunkIcon`), left alone | Blizzard bags at a merchant, Baganator |

The junk coin is the item button's `JunkIcon`. `ns.SetSlotCoin` hides it on junk-marked items and keeps it
hidden (Blizzard, Bagnon and Baganator all show it again on their next update). Baganator's own "Junk" corner
widget shows that same frame from the junk plugin's answer, so the plugin stays (Baganator's junk search,
category and grey option need it) and the coin is hidden by us.

## Marks on rows and controls

| Concept | Symbol | Where |
|---|---|---|
| Current / selected | teal nokta (`Media.nokta`, `nokta`), moves between rows | nav, menus, lists, settings, today in Ledger |
| Live / in progress / playing | orange nokta (`C.live`) | header, Junk sell button while selling, Auctions, Music card, docked notes |
| Checked option | `Media.check` in a checkbox | `Style.Checkbox` |
| Sort direction, dropdown caret | `Media.down` (▼) | List.lua headers, profession/character chips, Music |
| Price up / price down | `Media.up` in `danger` / `Media.down` in `nokta` | Items page |
| From → to | `Media.arrow` (→) | Craft page cost → sells |
| Close, dock, undock, settings | `Media.close`, `dock`, `undock`, `gear` | main window header |
| Remove a line | `×` text on a button | Buy at, Trade fill, Farm, Music chip |
| Count / times | `×` text, `×N` | everywhere |
| CraftWise itself | the W key (`Media.keyW`, `keyGold`) | TOC icon, minimap button, tooltip headers |
| Sheet corner | `Media.fold` as the cut corner of sheets and menus (decor, not a mark) | `Style.lua` |
