# CraftWise

WoW: Forever addon: crafting profit for every recipe you know **or can learn**.

## MVP
- Prices from Auctionator (`Auctionator.API.v1`), optional dependency
- Recipe list from the profession window: known + unlearned
- Profit table: cost, sells for (after 5% AH cut), profit, recipe status and learn cost

## Later
- Own AH scan (`C_AuctionHouse.ReplicateItems`)
- Price export via SavedVariables to velikopter.com

## Install (beta)
Copy `CraftWise/` to `World of Warcraft\_classic_beta_\Interface\AddOns\`.
